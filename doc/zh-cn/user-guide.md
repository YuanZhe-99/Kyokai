# 用户指南

Kyokai 让你看到并操作另一台电脑，也让 AI 为电脑的用户操作这台电脑——AI 总是在被操作的电脑上运行，使用那台电脑自己的 AI 服务商密钥。
本指南写给使用者；工作原理见本文件夹中的其他页面。

## 安装与启动

在 Windows 上运行安装程序：它只为你的用户安装，不需要管理员权限。Kyokai 启动后显示窗口，并在通知区域显示图标；关闭窗口后它仍在那里运行
（设置、通用中可以让关闭按钮改为退出）。除非打开“登录时打开”，Kyokai 不会随 Windows 启动。

Kyokai 用你的 Windows 账户加密保存它的机密——本机身份、密码、密钥。如果无法做到，主页会说明：此时每次启动设备 ID 都会改变。

## 本机

主页显示**本机**：设备 ID 是别人用来找到这台电脑的九位数字；**临时密码**在点“显示”之前是隐藏的。临时密码每次启动 Kyokai 以及每次点
**换一个密码**时都会改变；只把它告诉你想让其进入的人。设置、访问中还可以设置固定密码，供长期信任的设备使用。
设置、设备身份中可以设定这台电脑的**别名**，别人登录成功后会在设备 ID 旁看到它；留空则使用电脑的名称。

## 加入网络

设备通过 EasyTier 网络找到彼此。在**网络**页面填入运营你的网络的人提供的**服务器**（每行一个地址）、**网络名称**与**网络密钥**并保存。
页面随后会显示网络的状态、本机的地址，以及它能直连或经中继到达的 Kyokai 设备。设备宣告的 ID 只是提示：设备是谁要在连接时才得到证明。
**退出网络**会断开。除非打开**尝试直接连接**，连接都经由服务器中转；在双方网络允许时直接连接更快，此时 Windows 可能会询问是否允许 Kyokai 通过防火墙。

## 控制另一台设备

在主页的**控制另一台设备**中填入对方的设备 ID 与密码，点**连接**。默认会请求查看屏幕、使用鼠标和键盘以及共享剪贴板；打开
**同时请求在对方电脑上运行 AI 任务**可同时请求 AI 权限。对方电脑的用户随后会看到你的请求，并选择允许哪些：

| 权限 | 允许你 |
|---|---|
| 查看屏幕 | 看到对方电脑的屏幕 |
| 使用鼠标和键盘 | 在画面上操作它 |
| 共享剪贴板 | 在一端复制文本、在另一端粘贴 |
| 运行 AI 任务 | 给对方电脑的 AI 一个任务并控制它 |
| 批准 AI 操作 | 答复这些任务的批准请求 |

连接后，**查看**会在单独的窗口中打开对方的屏幕。画面下方的栏可设置画质（**更流畅**、**均衡**、**更清晰**）与帧率上限。点击画面即可在那里使用
鼠标和键盘；对方电脑上 Kyokai 自己的窗口绝不会收到你的输入。画面上方的栏可以**锁定屏幕**、发送 **Ctrl+Alt+Del**（对方以助手方式运行 Kyokai 时）以及在你操作期间**阻止对方的键盘和鼠标**，或打开**隐私模式**——对方屏幕会变黑，而你仍能看到；
对方用户随时可以用 Ctrl+Alt+Shift+Esc 或 Ctrl+Alt+Del 解除两者。你连接期间，对方电脑不会自行进入睡眠。**断开**会结束会话；关闭窗口只会停止画面。意外断开的会话会在一分钟内自动重连，
无需再次确认。

## 让别人控制本机

有人连接时，每个页面顶部都会出现请求，显示对方的设备 ID——已知的设备 ID 带着新密钥出现时会给出警告——以及对方所请求的每个权限的开关。
选择要允许的内容后点**允许**，或点**拒绝**。你允许过的设备列在设置、访问中；**移除**会立即撤销它并结束它的会话。**无需确认即可连接**让该设备在 30 天内仅凭固定密码即可进入，适用于无人值守的电脑。你自己使用键盘和鼠标时，
总是优先于对方，也优先于任何 AI。

## 以助手方式运行 Kyokai

设置中的**运行方式**决定本设备在哪里运行。**免授权**（默认）不需要任何东西。**随界面**与**后台服务**会在一次管理员提示后安装一次助手，
这样对方也能看到并操作本机的登录界面与管理员提示；后台服务还允许你设为无需确认的设备在有人登录之前连接。你的设备 ID、受信任设备与设置会随之迁移。
重新选择免授权会移除助手。

## 本机上的 AI

在 **AI** 页面的 **AI 服务商**中，从模板添加服务商（Claude 与 OpenAI 已经在列；OpenRouter、Gemini、通义千问、Ollama 等一点即可添加，
其他服务商可用**自定义**），填入 API 密钥，按 id 或用**列出模型**添加模型，并选择任务使用的**模型**。其他服务商需要能接收图片并调用工具的模型。还要选择何时询问你：**被标记的步骤和系统快捷键**（默认）
或**每个操作**。密钥保存在本机的机密存储中，不会再显示，除了发给服务商之外不发往任何地方。然后描述一个任务并点**开始**。

任务进行时，你能看到模型说了什么以及它的每个操作。需要你批准的操作会显示在带边框的框中，附**允许**与**拒绝**；其他页面上的横幅与通知会提醒你。
**暂停**、**继续**与**停止**随时可用。任务完成后可以回复以继续。**任务历史**保存已结束的任务（绝不保存截图），直到你清除它。

AI 会把本机屏幕的截图发送给你所选的服务商。Kyokai 自己的窗口不会出现在截图中，也不会出现在屏幕共享和其他远程桌面工具中。
如果要通过其他远程桌面工具查看和更改 Kyokai（例如在无人值守的电脑上），请在设置中关闭 **在屏幕采集中隐藏 Kyokai**；此时 AI 也能看到 Kyokai 的窗口。

## 另一台电脑上的 AI

在拥有**运行 AI 任务**的会话中，查看窗口有一个 AI 面板：描述任务并开始。任务在对方电脑上运行，使用那台电脑的服务商与密钥，面板会跟随它的进度。
拥有**批准 AI 操作**时，你可以答复它的批准请求；对方电脑的用户也始终可以答复，并且在你的任务运行期间会看到一个带**停止**的横幅。

## 安全

- 在一台电脑上使用键盘或鼠标会立即暂停它的 AI 任务；点击“继续”或“允许”后紧接着移动鼠标则不会。
- **Ctrl+Alt+Shift+Esc** 会停止正在运行的 AI 任务，托盘菜单中的**停止 AI 任务**也一样。控制方阻止了你的键盘和鼠标时，它也能把它们还给你。
- 控制端的人在查看窗口中使用鼠标或键盘时即为接管：AI 任务会先暂停。
- 控制端断开时，它的 AI 任务会暂停。
- 仅仅加入网络不授予任何权限；每个会话都需要密码，默认还需要你的确认。

## 备份身份

设置、**设备身份**中可以用**备份…**把本机身份存成由你选择的口令保护的文件，并在本机或另一台电脑上用**恢复…**恢复，那台电脑随后就拥有这个设备 ID。
**重置…**会让本机获得新的身份与设备 ID；认识旧身份的设备会看到警告，并可以选择**忘记旧身份**。

## 出现问题时

- “Kyokai 引擎没有运行。”：它的后台部分停止了；界面会显示原因，Kyokai 会重新启动它。日志位于设置、诊断中打开的文件夹。
- 网络显示错误：检查服务器地址、名称与密钥。
- 对方设备经中继到达：两边的网络都阻止了直连；可以正常使用，只是稍慢一些。
- AI 任务因错误停止：原因（密钥未被接受、服务商没有响应）会与任务一起显示。
