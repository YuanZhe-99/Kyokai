# 用户指南

Kyokai 让你看到并操作另一台电脑，也让 AI 为电脑的用户操作这台电脑——AI 总是在被操作的电脑上运行，使用那台电脑自己的 AI 服务商密钥。
本指南写给使用者；工作原理见本文件夹中的其他页面。

## 安装与启动

在 Windows 上运行安装程序：它只为你的用户安装，不需要管理员权限。Kyokai 启动后显示窗口，并在通知区域显示图标；关闭窗口后它仍在那里运行
（“通用”中可以让关闭按钮改为退出）。除非打开“登录时打开”，Kyokai 不会随 Windows 启动；登录时启动的 Kyokai 不打开窗口，只在通知区域（Mac 上为菜单栏）中等待。

在 macOS 上，打开磁盘映像并把 Kyokai 拖到“应用程序”。Kyokai 已签名但未经 Apple 公证，因此 macOS 可能称下载的应用已损坏：在“终端”中运行一次 `xattr -dr com.apple.quarantine /Applications/Kyokai.app`，再打开它。Kyokai 首次启动时会请求**屏幕录制**（让其他人看到这块屏幕）、**辅助功能**（让其他人使用鼠标和键盘）和**输入监控**（你自己使用键盘和鼠标时暂停 AI 任务，按 Control+Option+Shift+Esc 可停止它）。请在系统设置的“隐私与安全性”中允许它们；主页和设置中的**隐私权限**会显示仍缺少什么，点**允许…**即可打开相应面板。允许的权限要在 Kyokai 再次启动后才生效：点该行的**重新打开 Kyokai**。也请允许 Kyokai 使用它的钥匙串项目（**始终允许**）；如果曾经拒绝，点钥匙串一行的**允许…**会再次询问。

Kyokai 用你的 Windows 账户加密保存它的机密——本机身份、密码、密钥。如果无法做到，主页会说明：此时每次启动设备 ID 都会改变。

## 本机

主页显示**本机**：设备 ID 是别人用来找到这台电脑的九位数字；**临时密码**在点“显示”之前是隐藏的。临时密码每次启动 Kyokai 以及每次点
**换一个密码**时都会改变；只把它告诉你想让其进入的人。“权限”中还可以设置固定密码，供长期信任的设备使用。
“安全”的设备身份中可以设定这台电脑的**别名**，别人登录成功后会在设备 ID 旁看到它；留空则使用电脑的名称。

## 加入网络

设备通过 EasyTier 网络找到彼此。在**网络**页面选择**添加网络**，填入运营你的网络的人提供的**服务器**（每行一个地址）、**网络名称**与
**网络密钥**，可以再为它填一个显示的名称，然后保存：设备会立即加入。最多可以保存 8 个网络，并同时加入其中几个（每个都有自己的**加入**开关）；
本设备在所有网络中的设备 ID 都相同，所以你任一网络中的设备都能连接它。每个网络会显示它的状态、本机在其中的地址，以及它能直连或经中继
到达的 Kyokai 设备。设备宣告的 ID 只是提示：设备是谁要在连接时才得到证明。按设备 ID 连接时，会尝试每个列出该设备的已加入网络，先试
直接路径。**编辑**修改一个网络；**移除**会离开它并忘记它的设置。

除非打开**尝试直接连接**（在“网络”页面中，切换后立即生效），连接都经由服务器中转；在双方网络允许时直接连接更快，此时 Windows 可能会询问是否允许 Kyokai 通过防火墙，Mac 可能会询问是否允许它查找本地网络中的设备。在同一网络中只需其中一台电脑打开；不同网络中的电脑请在两台上都打开。列表中的每台设备都有“复制”与“连接”。没有网络时也可以按地址连接（见下文）。

## 控制另一台设备

在主页的**控制另一台设备**中填入对方的设备 ID 并点**连接**，或点击**最近**下的某台设备（绿点表示它在你的网络中）。默认会请求查看屏幕、使用鼠标和键盘、共享剪贴板以及复制文件；**选项** › **同时请求在对方电脑上运行 AI 任务**，或设备 ⋯ 菜单中的**连接并使用 AI**，会同时请求 AI 权限。连接会作为一个标签页在主页旁打开。询问对方用户期间，标签页也允许你改为输入对方的密码；打开**记住密码**会把它（加密）保存以便下次使用，设备菜单中的**忘记密码**会忘记它。密码正确时，你会立即进入，获得对方允许密码授予的权限；更多的权限需要对方用户确认。对方电脑的用户选择允许哪些：

| 权限 | 允许你 |
|---|---|
| 查看屏幕 | 看到对方电脑的屏幕 |
| 使用鼠标和键盘 | 在画面上操作它 |
| 共享剪贴板 | 在一端复制文本、在另一端粘贴 |
| 复制文件 | 在一端复制文件或文件夹、在另一端粘贴（每次最多 1000 项、1 GiB） |
| 运行 AI 任务 | 给对方电脑的 AI 一个任务并控制它 |
| 批准 AI 操作 | 答复这些任务的批准请求 |

连接后，标签页显示对方的屏幕。把标签页拖出窗口（或点它的 ⧉）即可得到单独的窗口，拖到另一个 Kyokai 窗口上即移到那里；**全屏**会占满屏幕。画面下方的栏可设置画质（**更流畅**、**均衡**、**更清晰**）、帧率上限与**编码**（**自动**由对方电脑选择；列表中是两台电脑都支持的编码）。它还说明连接是**直连**还是**中继**；其数字的提示说明时间花在哪里。**适应窗口**在窗口中显示整个屏幕；**原始大小**按对方电脑每个像素一个点显示，比窗口大时可拖动滚动条查看。点击画面即可在那里使用
鼠标和键盘；对方电脑上 Kyokai 自己的窗口只在对方用户关闭了**在屏幕采集中隐藏 Kyokai**时才会收到你的输入，有连接请求或 AI 批准在那里等待时也不会收到。画面上方的栏可以**锁定屏幕**、发送 **Ctrl+Alt+Del**（对方以助手方式运行 Kyokai 时）以及在你操作期间**阻止对方的键盘和鼠标**，或打开**隐私模式**——对方屏幕会变黑，而你仍能看到；
对方用户随时可以用 Ctrl+Alt+Shift+Esc 或 Ctrl+Alt+Del 解除两者。这一栏还决定你的键盘如何到达对方电脑：**映射**（默认）按键位发送每个键，
由对方的键盘布局决定输入的字符，Windows 键、Alt+Tab、Cmd+Tab 等快捷键也会送到那里；**翻译**用你自己的键盘布局和输入法输入；
**传统**只发送查看窗口收到的按键。在 Mac 上，映射与翻译需要在“系统设置”的“隐私与安全性”中为 Kyokai 打开**辅助功能**。在 Mac 与
Windows 之间，**交换 Ctrl 与 Cmd**（默认打开）让你习惯的快捷键在对方电脑上照常工作：Cmd+C 在 Windows 电脑上复制，Ctrl+C 在 Mac 上
复制。顶部的栏和底部的状态栏都可以收起（⌃ 与 ⌄），让画面占据更多空间；边缘留下的小标签可以把它们拉回来，Kyokai 会为该设备记住。只有画面拥有焦点时按键才会送过去：请先点击画面。你能听到对方电脑播放的声音（或对方用户在“权限”的**共享的声音**中选择的输入，例如麦克风；此时 Mac 会请求“麦克风”权限）；状态栏中的**声音**可以关闭它。**剪贴板**拉出剪贴板面板：**与这台设备共享剪贴板**为该设备关闭或打开共享，其下是它的标签页位于前台期间经过剪贴板的内容——来自该设备或来自本机，最新的在前，文本带**复制**——只保留到关闭标签页为止。连接了多台设备时，只有标签页位于前台（在你最近使用的 Kyokai 窗口中）的那台设备共享剪贴板；切换到某个标签页时，会把这期间复制的内容发送过去。画质、帧率、适应窗口或原始大小、编码、声音、这一交换以及剪贴板开关会按设备记住。你连接期间，对方电脑不会自行进入睡眠。关闭标签页（×）即断开连接；连接结束时，标签页会说明原因并提供**重新连接**。意外断开的连接会在一分钟内自动重连，无需再次确认。设备菜单中的**移除**会把它从最近中移除，并忘记保存的密码。**重命名…**为它起一个只在本机显示的名称；留空即恢复使用设备自己的名称。

### 按地址连接

在同一局域网中、经由 Tailscale，或在任何能到达对方电脑的地方，你都可以不加入网络直接连接：在设备 ID 的位置填入它的 IP 地址或域名（端口不是 47310 时加上 `:端口`），然后点**连接**。Kyokai 会先询问那里是哪台设备，再连接到它；之后“最近”会记住这个地址。对方电脑必须允许：“网络”页面中的**接受地址直接连接**（默认关闭）。它只接受来自所列地址网段的连接——默认为局域网和 Tailscale——并且仍然需要密码或对方用户的批准。Windows 可能会询问是否允许 Kyokai 通过防火墙。

## 让别人控制本机

知道你密码的人会立即进入，获得“权限”中**使用正确密码时**允许的权限（默认是查看屏幕、鼠标和键盘、剪贴板与文件，不含 AI 任务）。
否则——对方请求更多、不使用密码而请求，或已知的设备 ID 带着新密钥出现——每个页面顶部都会出现请求，显示对方的设备 ID，后两种情况会给出警告，以及对方所请求的每个权限的开关。
选择要允许的内容后点**允许**，或点**拒绝**。你允许过的设备列在“权限”中；**移除**会立即撤销它并结束它的连接。在那里，**接受的密码**决定哪些密码可以让设备进入（**临时密码**、**固定密码**或**两者**），**无需确认即可连接**（默认开启）让正确的密码无需询问你即可进入；关闭后每次都会询问你。没有人在这台电脑前时（后台服务），只有固定密码可以进入。你自己使用键盘和鼠标时，
总是优先于对方，也优先于任何 AI。

## 以助手方式运行 Kyokai

“通用”中的**运行方式**决定本设备在哪里运行。**免授权**（默认）不需要任何东西。**随界面**与**后台服务**会在一次管理员提示后安装一次助手，
这样对方也能看到并操作本机的登录界面与管理员提示；后台服务还允许你设为无需确认的设备在有人登录之前连接。你的设备 ID、受信任设备与设置会随之迁移。
重新选择免授权会移除助手。

在 Mac 上，助手以 **Kyokai Helper** 的身份查看并控制屏幕，它需要自己的屏幕录制与辅助功能（设备控制与数据访问）权限：切换之后，在“权限”中打开**隐私权限**，点**允许…**，在打开的面板中打开 Kyokai Helper 的开关，然后点**重启 Kyokai Helper**。在 Mac 上切回免授权不需要密码。

## 本机上的 AI

在 **AI** 页面的 **AI 服务商**中，从模板添加服务商（Claude 与 OpenAI 已经在列；OpenRouter、Gemini、通义千问、Ollama 等一点即可添加，
其他服务商可用**自定义**），填入 API 密钥，按 id 或用**列出模型**添加模型，并选择任务使用的**模型**。其他服务商需要能接收图片并调用工具的模型。还要选择何时询问你：**被标记的步骤和系统快捷键**（默认）
或**每个操作**。密钥保存在本机的机密存储中，不会再显示，除了发给服务商之外不发往任何地方。然后描述一个任务并点**开始**。

任务进行时，你能看到模型说了什么以及它的每个操作。需要你批准的操作会显示在带边框的框中，附**允许**与**拒绝**；其他页面上的横幅与通知会提醒你。
**暂停**、**继续**与**停止**随时可用。任务完成后可以回复以继续。**任务历史**保存已结束的任务（绝不保存截图），直到你清除它。

AI 会把本机屏幕的截图发送给你所选的服务商。Kyokai 自己的窗口不会出现在截图中，也不会出现在屏幕共享和其他远程桌面工具中。
如果要通过其他远程桌面工具查看和更改 Kyokai（例如在无人值守的电脑上），请在“安全”中关闭 **在屏幕采集中隐藏 Kyokai**（Kyokai 会先询问）：此时 AI 也能看到 Kyokai 的窗口，通过 Kyokai 控制这台电脑的人也能操作它们。AI 永远不能操作；有连接请求或 AI 批准在等待你时，任何人都不能操作。

## 另一台电脑上的 AI

拥有**运行 AI 任务**时，连接的标签页有一个 AI 面板（可用 **AI** 开关隐藏）：描述任务并开始。任务在对方电脑上运行，使用那台电脑的服务商与密钥，面板会跟随它的进度。连接到那台电脑的每个人看到的都是同一个任务和同一份正在输入的草稿，那台电脑自己的 AI 页面也一样。
拥有**批准 AI 操作**时，你可以答复它的批准请求；对方电脑的用户也始终可以答复，并且在你的任务运行期间会看到一个带**停止**的横幅。

## 安全

- 在一台电脑上使用键盘或鼠标会立即暂停它的 AI 任务；点击“继续”或“允许”后紧接着移动鼠标则不会。
- **Ctrl+Alt+Shift+Esc** 会停止正在运行的 AI 任务，托盘菜单中的**停止 AI 任务**也一样。控制方阻止了你的键盘和鼠标时，它也能把它们还给你。
- 控制端的人在查看窗口中使用鼠标或键盘时即为接管：AI 任务会先暂停。
- 控制端断开时，它的 AI 任务会暂停。
- 仅仅加入网络不授予任何权限；每个会话都需要你的密码或你的确认。
- **保护模式**（“安全”；需要固定密码）让这台电脑上的 Kyokai 只剩 AI 设置和 AI 任务，适合应当在这里使用 AI 但不能更改其他内容的人。要关闭它，在 AI 页面输入固定密码。
- **完全无日志**（“安全”）让 Kyokai 不写日志或崩溃报告，也不保留连接记录：受信任设备与“最近”只保留到 Kyokai 退出为止，已经写下的日志会被删除。这是一种取舍：此后你将无法知道谁连接过这台电脑、这台电脑连接过哪些设备，所以打开前 Kyokai 会先询问。

## 备份身份

“安全”的**设备身份**中可以用**备份…**把本机身份存成由你选择的口令保护的文件，并在本机或另一台电脑上用**恢复…**恢复，那台电脑随后就拥有这个设备 ID。
**重置…**会让本机获得新的身份与设备 ID；认识旧身份的设备会看到警告，并可以选择**忘记旧身份**。

## 出现问题时

- “Kyokai 引擎没有运行。”：它的后台部分停止了；界面会显示原因，Kyokai 会重新启动它。日志位于“关于”的诊断中打开的文件夹。
- 网络显示错误：检查服务器地址、名称与密钥。
- 对方设备经中继到达：在两台设备上都打开**尝试直接连接**（在“网络”页面中）；如果仍是中继，说明网络阻止了直连：可以正常使用，只是稍慢一些。
- AI 任务因错误停止：原因（密钥未被接受、服务商没有响应）会与任务一起显示。
- Kyokai 不再响应或关闭了：开启日志时，日志文件夹（“关于”的诊断）中的 `gui-crash.log` 与 `engine.log` 会记下它当时在做什么——窗口卡住 10 秒后会把状态写到那里。在 Mac 上，用 `kill -QUIT` 加 Kyokai 的进程号可以立即写下；崩溃的引擎的报告由系统保存在 `~/Library/Logs/DiagnosticReports`（`kyokai-svc-…`）中，`log show --last 1h --predicate 'process == "Kyokai" OR process == "kyokai-svc"'` 会显示 macOS 记下的内容；把这些连同经过描述一起发送。
