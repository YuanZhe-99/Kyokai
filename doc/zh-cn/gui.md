# 界面

界面面向使用 Kyokai 的人，而不是工程控制台（`internal/gui`）。`internal/gui/gui_test.go` 以每种语言和主题渲染每个页面，
设置 `SCREENSHOT_DIR` 时写出截图。

## 结构

- **侧栏：** 主页、网络、AI、设置。
- **主页：** “本机”——按三位一组显示的设备 ID 及“复制”；临时密码，在点“显示”前遮蔽，可“复制”和“换一个密码”；
  机密未持久化时显示提示。下方是“控制另一台设备”（设备 ID、密码、连接；需要先加入网络）以及会话列表，最新的在前（连接到或
  来自哪台设备、状态或失败原因、断开；被控端密钥变化时提供“忘记旧身份”）。表单下方以按钮列出最近设备，点击即填入设备 ID；意外断开的会话在恢复期间
  显示“正在重新连接”。可以查看屏幕的已连接会话有“查看”按钮，用来打开查看窗口：一个独立窗口，在黑色背景上按比例显示画面，
  并带有状态行（设备 ID、画质预设、帧率上限、尺寸、编解码器、帧率、码率、被控端测得的延迟）；关闭窗口只停止视频流，不结束会话。拥有 `control-input` 时，画面上的鼠标、滚轮与键盘操作会发送到被控端
  （[computer-use.md](computer-use.md)）。拥有 `run-ai-task` 时，查看窗口侧边有 AI 面板：指令与“开始”，之后像 AI 页面那样显示被控端的任务
  （状态、模型的文字、最近的操作、“暂停”或“继续”和“停止”、完成后的回复）；拥有 `approve-ai-action` 时其批准请求带“允许”“拒绝”，
  否则提示由被控端用户批准。这样的会话即使没有 `view-screen` 也有“查看”。连接表单的开关“同时请求在对方电脑上运行 AI 任务”会一并请求
  `run-ai-task` 与 `approve-ai-action`。
- **确认：** 等待被控端用户确认的控制端显示在每个页面顶部，包括其设备 ID、是否已知或是冒用已知 ID 的新密钥，以及每个所请求
  权限的开关，并提供“允许”与“拒绝”；同时发出通知并把窗口带到前面。
- **AI：** 任务卡片——新任务的指令与“开始”（服务商没有密钥时给出提示），或进行中的任务：以文字说明其状态（正在操作、
  等待批准、已暂停及原因、已完成、已停止），模型最新的文字与进度说明，以文字描述的最近几个操作（“在 640, 425 处单击”、
  “按 Ctrl+S”）及其结果，以及“暂停”或“继续”和“停止”；等待批准的操作显示在带边框的框中，附“允许”“拒绝”与服务商的说明。
  已完成的任务可以通过回复继续。下方是服务商卡片（Claude 或 OpenAI、模型、只写的 API 密钥字段、“移除密钥”、批准方式）
  以及带“清除历史”的任务历史。任务等待批准期间，其他每个页面都会显示带“查看”的横幅，并发出通知。控制端的任务会显示“由”其设备 ID“发起”，
  它工作期间，其他每个页面都会显示带“查看”与“停止”的横幅。
- **网络：** 节点的实时状态（已连接、正在连接，或无法连接的原因；虚拟地址；用通俗说法描述的 NAT 类型）以及它能
  路由到的 Kyokai 设备（设备 ID、直连或中继、延迟），并提示设备宣告的 ID 不能作为证明；下方是设置表单：服务器（每行
  一个 URL）、网络名称和只写的密钥字段（留空保留已存的密钥；弱密钥会被标出），以及“保存”和“退出网络”。被拒绝的
  设置会显示引擎给出的原因。
- **设置：** 通用（语言、外观、登录时打开——默认关闭、关闭按钮）、设备身份（设备 ID、指纹；通过文件对话框以口令备份和恢复；在警告后重置）、访问（固定密码：设置、更改或移除；受信任设备及其最近连接时间与“移除”）、存储（数据文件夹及
  “打开文件夹”、机密的保存方式）、诊断（版本与 ABI、引擎启动时间、运行方式、日志文件夹）、关于（版本、许可证、源代码、
  应用更新）、开源许可证（随附的声明）。
- 引擎会话连接之前，需要它的页面显示“正在启动…”或引擎未运行的原因。
- **应用更新（关于）：** 每日检查（可关闭）与“检查更新”读取 GitHub 最新发布的已签名更新；“安装并重启”会先停止引擎，
  就地安装后重新启动。开发版本会说明无法自行更新。

## 措辞规则

- 文案写给使用应用的人。
- 从不显示：原因代码、密钥、套接字路径、除设备 ID 以外的内部标识（指纹只出现在身份卡片上）。

## 视觉语言

- MyGo 浅色/深色主题加系统强调色；布局数字是 `style.go` 中的命名常量。
- 正文 14，标题 20–24，不小于 12；设备 ID 为 34，使用等宽数字。
- 应用图标为原创作品：一个被边界线（鏡界）分开的圆环，一侧实心、一侧描边，一个指针跨过边界。托盘以单色模板图形
  显示同一标志。`go run ./tools/icon resources/icon.png internal/gui/assets/tray.png` 按其几何形状绘制两者。

## 托盘

- 菜单：设备 ID（不可点）、有任务进行时的“停止 AI 任务”（紧急停止）、显示 Kyokai、退出 Kyokai。从不显示密码。
- Kyokai 的窗口不参与屏幕采集，因此查看窗口和 AI 任务都看不到它们。
- 关闭窗口时隐藏到托盘，并在第一次时说明；没有托盘，或关闭按钮选择“退出”时，关闭即退出。

## 语言

通过 MyGo 的 ARB 目录支持英文、简体中文、繁体中文与日文（`go tool mygo i18n check`）。应用跟随系统语言，也可手动切换。
