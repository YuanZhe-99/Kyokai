# 界面

界面面向使用 Kyokai 的人，而不是工程控制台（`internal/gui`）。`internal/gui/gui_test.go` 以每种语言和主题渲染每个页面，
设置 `SCREENSHOT_DIR` 时写出截图。

## 结构

- **侧栏：** 主页、设置。
- **主页：** “本机”——按三位一组显示的设备 ID 及“复制”；临时密码，在点“显示”前遮蔽，可“复制”和“换一个密码”；
  机密未持久化时显示提示。
- **设置：** 通用（语言、外观、登录时打开——默认关闭、关闭按钮）、设备身份（设备 ID、指纹）、存储（数据文件夹及
  “打开文件夹”、机密的保存方式）、诊断（版本与 ABI、引擎启动时间、运行方式、日志文件夹）、关于（版本、许可证、源代码、
  应用更新）、开源许可证（随附的声明）。
- 引擎会话连接之前，需要它的页面显示“正在启动…”或引擎未运行的原因。
- **应用更新（关于）：** 每日检查（可关闭）与“检查更新”读取 GitHub 最新发布的已签名更新；“安装并重启”会先停止引擎，
  就地安装后重新启动。开发版本会说明无法自行更新。

## 措辞规则

- 文案写给使用应用的人。
- 从不显示：原因代码、密钥、套接字路径、除设备 ID 以外的内部标识（指纹只出现在身份卡片上）。

## 视觉语言

- MyGo 浅色/深色主题加系统强调色；布局数字是 `style.go` 中的命名常量。
- 正文 14，标题 20–24，不小于 12；设备 ID 为 34，使用等宽数字。
- 应用图标为原创作品：两块屏幕隔着一条边界线互为镜像（鏡界）。

## 托盘

- 菜单：设备 ID（不可点）、显示 Kyokai、退出 Kyokai。从不显示密码。
- 关闭窗口时隐藏到托盘，并在第一次时说明；没有托盘，或关闭按钮选择“退出”时，关闭即退出。

## 语言

通过 MyGo 的 ARB 目录支持英文、简体中文、繁体中文与日文（`go tool mygo i18n check`）。应用跟随系统语言，也可手动切换。
