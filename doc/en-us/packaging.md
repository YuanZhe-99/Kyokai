# Packaging

`scripts/build.sh [goos/goarch …]` builds, per target, libvpx and libaom (`scripts/codecs.sh`,
linked statically into the core), the Rust core (`cargo build --release`) and the engine
(`kyokai-svc`, `CGO_ENABLED=0`) into `resources/<goos>-<goarch>/bin`, copies `LICENSE`,
`THIRD_PARTY_NOTICES.md` and `third_party/licenses` into `resources/licenses`, and runs
`go tool mygo build`.
Windows targets need a Windows host (the core links with MSVC; an ARM64 machine also builds x64);
macOS targets need a Mac. `CORE_PREBUILT=1` uses core libraries already placed in the resources
(the release workflow), and `MYGO_SIGN` passes a signing identity to `mygo build -sign`.

## Artifacts

| Platform | Files |
|---|---|
| Windows (x64, ARM64) | `Kyokai.exe` with `bin/kyokai-svc.exe`, `bin/kyokai_core.dll` and `licenses/`; a per-user NSIS installer (`%LOCALAPPDATA%\Programs\Kyokai`, no administrator rights); a portable zip |
| macOS (Apple silicon, Intel) | `Kyokai.app` with `Contents/Resources/bin/kyokai-svc` (the app's engine) and `bin/Kyokai Helper.app` (the core library and the helper's own engine, [run-modes.md](run-modes.md)), and a `.dmg` |
| Both | with `MYGO_UPDATER_PRIVATE_KEY`: the signed update archive, deltas and `update-<target>.json` |

Built files under `resources/<goos>-<goarch>/` and `resources/licenses/` are not committed.

## Signing

- **Updates:** Ed25519 (MyGo updater); the archive covers the whole app, the core library
  included.
- **macOS code signing:** release builds use the maintainer's Apple Development certificate (a
  free Personal Team, so a Team ID), imported into a temporary keychain on the runner; the workflow
  signs with the identity's SHA-1 (locally: `MYGO_SIGN` names it). With a Team ID the Screen
  Recording, Accessibility and Input Monitoring grants and the Keychain's Always Allow hold across
  builds and updates (checked on macOS 27). The apps are not notarized, so Gatekeeper still asks
  "Open Anyway" on first launch. The certificate lasts a year: renew it in Xcode, export the
  `.p12` and replace both secrets. `packaging/macos/app.entitlements` and
  `packaging/macos/engine.entitlements` (`macos.helperEntitlements` for `bin/kyokai-svc` and
  `bin/Kyokai Helper.app`) disable library validation under the hardened runtime. Without the
  certificate the app is ad hoc signed.
- **Windows:** not code signed; SmartScreen warns on first launch. With `KYOKAI_SIGNING_KEY` the
  `bin` folder also holds `bundle.json` and `bundle.sig`, which an installed helper checks before it
  updates itself ([run-modes.md](run-modes.md), "Updates").

## Licenses

Kyokai is AGPL-3.0-only. Every package carries `licenses/LICENSE` and
`licenses/THIRD_PARTY_NOTICES.md`, which the Settings page shows; the About page links the source.
It also carries `licenses/RUST_LICENSES.txt` — every Rust crate in the core with its license text,
generated by `cargo about` from `core/about.toml` and `core/about.hbs` — and
`licenses/GPL-3.0.txt`, which EasyTier's LGPL-3.0 asks to accompany it, and the native codec
libraries' texts from `third_party/licenses`: `libvpx-LICENSE.txt` (BSD-3-Clause) with
`libvpx-PATENTS.txt` (Google's patent grant) and `libaom-LICENSE.txt` (BSD-2-Clause) with
`libaom-PATENTS.txt` (the Alliance for Open Media Patent License 1.0). The build stops when
`cargo-about` is missing.

## Vendor logos

The device avatars' vendor logos ([gui.md](gui.md), "Device names") are SVG files in
`internal/gui/assets/logos/`, embedded into the GUI at build time; the app never downloads them.
They come from EasyTier MyGo's set: 18 Simple Icons files (CC0 1.0) and one public-domain file, each
listed with its source, license and trademark owner in `SOURCES.md`; files without a recorded
source were left out. To add one, take a CC0 or public-domain SVG, save it as `<slug>.svg`, add its
row to `SOURCES.md`, its words to `vendorKeywords` in `internal/gui/vendorlogo.go` and a case to
`TestDeviceLogoName`; `TestVendorLogosParse` fails for a file that does not parse or a keyword whose
logo is missing.
